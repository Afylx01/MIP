2. NIFTY50, NIFTY100, NIFTY200, NIFTYNEXT50, NIFTYMIDCAP100, NIFTYSMALLCAP100:
   - Absence of Seed Batches: Unlike NIFTY500, these 6 sheets contain replacement change events only.
     For every rebalance date, an exclusion (OUT) is matched with an inclusion (IN), resulting in total INs == total OUTs.
     Because the initial constituents (at index inception in 1996, 2000, 2003, 2005, 2011) were never entered
     into IndexInclExcl.xls as IN events, when those pre-existing members are excluded, they emerge as orphan OUTs
     in any naive forward replay started from an empty set. This is a structural property of the source spreadsheet,
     confirming the Phase 5.5 Gate 2b ruling: 'event log only, not reconstructable' for non-NIFTY500 indices.

3. Identified Sheet-Level Event Anomalies:

     without trailing period (Row 68 on 2003-08-04). Under exact string matching, this left the dotted name active,
     causing a duplicate IN when SAIL was re-included on 2012-09-28 (Row 218). Under symbol mapping or token stripping,
     both resolve to SAIL / INE114A01011, eliminating the duplicate.
   - NIFTYMIDCAP100: 'Indiabulls Real Estate Ltd.' recorded consecutive IN events on 2011-10-10 (Row 156) and
     2012-04-27 (Row 171) without an intervening OUT event. This is an uncorrected source-log anomaly.
