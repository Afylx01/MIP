### Task 1: Macro Market Regime Stress Test (Gate 17)
- **Script**: `deliverables/phase_7/scripts/test_macro_regimes.py`
- **Methodology**:
  - Segment the 2007–2026 history into 6 distinct Indian macroeconomic and market regimes:
    1. **2008 Global Financial Crisis** (`2008-01-01` to `2008-12-31`): Extreme liquidity freeze and -64% NIFTY drawdown.
    2. **2009–2010 Post-GFC V-Recovery** (`2009-01-01` to `2010-12-31`): Rapid cyclical rebound.
    3. **2011–2013 Stagnant Bear / Choppy Sideways** (`2011-01-01` to `2013-12-31`): High inflation, policy paralysis.
    4. **2014–2017 Midcap Momentum Bull Run** (`2014-01-01` to `2017-12-31`): Sweeping electoral mandate, strong rally.
    5. **2018–2019 NBFC Liquidity Crisis & Smallcap Meltdown** (`2018-01-01` to `2019-12-31`): IL&FS default, polarized NIFTY.
    6. **2020 COVID Crash & 2021–2026 Supercycle** (`2020-01-01` to `2026-08-31`): Acute crash followed by broad-based bull run.
  - Replay the baseline momentum strategy across each isolated regime.
- **Pass Threshold**: Each regime documented with tearsheets. Maximum drawdown $< 50.0\%$; maximum drawdown recovery $< 3.0$ years. Zero unrecoverable drawdown traps ($> 70.0\%$).
- **Fail Threshold**: Max Drawdown $> 70.0\%$ in any regime or recovery time $> 5.0$ years.

### Task 2: Random Top-20 Monte Carlo Control (Gate 18)
- **Script**: `deliverables/phase_7/scripts/test_random_monte_carlo.py`
- **Methodology**:
  - Evaluate whether the strategy's alpha is generated by the **Volar / 252d return ranking**, or if simply holding any 20 stocks that pass the filters (52w High, 200 EMA, RS) produces identical returns.
  - Run **1,000 bootstrap simulations** across 2016–2026:
    - At each monthly rebalance, randomly select 20 stocks from the candidate universe that pass Filters 1, 2, and 3.
    - Track the equity curve and compute CAGR for each random run.
  - Compare actual strategy CAGR against the distribution of random portfolios.
- **Pass Threshold**: Strategy CAGR beats the median random portfolio CAGR by $> 3.0$ percentage points; empirical $p$-value $< 0.05$ (statistically superior at 95% confidence).
- **Fail Threshold**: Strategy CAGR is within the random portfolio interquartile range ($p \ge 0.05$).
- **Export**: `deliverables/phase_7/data_csv/gate18_random_monte_carlo.csv`.

### Task 5: Advanced Statistical Significance & Multiple-Testing Deflation (Gates 23, 24, 25)
- **Script**: `deliverables/phase_7/scripts/test_statistical_significance.py`
- **Methodology**:
  - **Gate 23 (Newey-West HAC Significance)**:
    - Run regression on monthly excess returns with Newey-West HAC (heteroskedasticity and autocorrelation consistent) robust standard errors (lag order = 6).
    - *Pass Threshold*: Newey-West $t$-statistic on alpha intercept $> 2.00$ ($p < 0.05$).
    - *Fail Threshold*: $t$-stat $< 1.50$.
  - **Gate 24 (Stationary Bootstrap Confidence Intervals)**:
    - Run **10,000 stationary block bootstrap resamples** of monthly returns (Politis & Romano block bootstrap).
    - Compute the empirical distribution of annualized CAGR and Sharpe Ratio.
    - *Pass Threshold*: 5th percentile bootstrap CAGR strictly exceeds benchmark CAGR ($> 11.14\%$).
    - *Fail Threshold*: 5th percentile CAGR falls below benchmark.
  - **Gate 25 (Deflated Sharpe Ratio - DSR)**:
    - Apply Bailey & López de Prado (2014) Deflated Sharpe Ratio to correct for multiple testing, non-normality (skewness and kurtosis), and sample length across all evaluated parameter combinations ($N = 54$).
    - *Pass Threshold*: Deflated Sharpe Ratio $> 0.50$.
    - *Fail Threshold*: Deflated Sharpe Ratio $< 0.30$.
- **Export**: `deliverables/phase_7/data_csv/gates_23_25_statistical_significance.csv`.
